# AI Nutrition Advisor - Frontend

React + Vite frontend for AI Nutrition Advisor.

## 🚀 Deploy to Vercel

1. Log in to [Vercel](https://vercel.com).
2. Click **Add New...** -> **Project**.
3. Import `gugulothuvyshali3/AI_Nutrition_frontend`.
4. Framework Preset: **Vite** (detected automatically).
5. Add Environment Variable:
   - `VITE_API_URL` = `https://<your-backend-app-name>.onrender.com`
6. Click **Deploy**.

## 💻 Local Development

```bash
npm install
npm run dev
```
